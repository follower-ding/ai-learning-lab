# 第 04 课：向量库

向量本身不能当答案。库把稳定 id、原文、向量和少量 metadata 放在同一条记录里，按余弦取出最接近的几条。

## 学习目标

- 写入时检查维度和重复 id。
- 查询用和文档同一次 `fit` 的向量。
- 看懂 top-k 里可以有很低的分数，删不删留给阈值。

## 概念笔记

`MemoryVectorStore` 只为课程这种几十条记录准备。`add` 记下四样东西：

- `id`：后面引用要用的稳定名字，例如 `faq-checkin`。
- `text`：给人和模型读的原文。短问答存的是正文，标题只参加向量，避免引用时把标题再贴一遍。
- `vector`：`TfidfEmbedder` 算出来的那一串数。
- `metadata`：至少有 `source_id` 和 `title`。切块之后，块可以有自己的 id，引用仍回到文档 id。

搜索时对每条记录算余弦，按分数从高到低排。分数相同就按 id 字母序排，所以「游泳池」这种全是 0 分的查询仍有固定顺序。那个顺序不表示早餐比入住更相关。

维度不一致就抛 `VectorDimensionError`，不截断、不补零。重复 id 也拒绝，避免静默覆盖后引用指向了另一段正文。换嵌入模型要整库重算，不能只重算新问题。

这一课的资料用短问答，一条一篇。长规章的切块在第 03 课已经看过。短的常见问答不必为了切而切。

## 跑起来

```bash
python lessons/04-vector-store/exercise.py
```

库里是 7 条。「入住时间是什么时候」的第一条应当是 `faq-checkin`，分数大约 0.40，第二条掉到 0.15 以下。「游泳池几点开放」三条都是 0.000。

建议改一行：把 `k` 改成 `1`。低分的邻居不再出现，但你也看不见「第二名差多远」。阈值还没上场，只是少看了几行。

## 常见坑

- 只存向量，不存原文和 id。下一课无法引用，也无法核对正文。
- 把 top-k 里的低分结果当成「相关」。相关与否要有阈值，阈值在第 05 课。
- 查询用了另一套向量空间，或和文档的维度不同，还试图比较。
- 相同分数的顺序被读成相关度。全 0 时只是 id 的字母序。
