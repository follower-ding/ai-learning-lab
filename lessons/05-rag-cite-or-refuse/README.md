# 第 05 课：引用或拒绝

检索不是把库里的话都交给模型。分数不够就拒绝，并且不调用模型。模型若引用了这次没检索到的文档，草稿整段作废。

## 学习目标

- 用 `DEFAULT_MIN_SCORE` 把 top-k 分成「可以交给模型」和「不够」。
- 回答里的 `[faq-...]` 必须落在这一次过了阈值的 id 上。
- 拒绝时只输出固定的那句说明，不保留草稿里的半句。

## 概念笔记

`RagPipeline.answer` 的顺序是固定的：

1. 把问题嵌入，取出 top-k。
2. 丢掉分数低于 `DEFAULT_MIN_SCORE`（当前是 0.2）的命中。一条都不剩，就返回「知识库里没有足够依据，不能回答。」原因记为 `low_score`。这一支不调用 `complete`。
3. 把留下的段落写进系统提示，标上 `[faq-checkin]` 这种 id。
4. 检查模型草稿里的引用。没有引用，原因是 `missing_citation`。出现了不在允许集合里的 id，原因是 `unknown_citation`。两种情况都改成同一句拒绝，草稿不留。

0.2 只对当前这份短问答和 `TfidfEmbedder` 有意义。自带资料上，住客真会问到的那几句，最高分大约在 0.28 到 0.40；游泳池、机场接送是 0。第 03 课那句「我什么时候能进房间」大约 0.23，擦着阈值，改资料或换嵌入模型之后都要重新看分数，不能把 0.2 当成通用常数。

练习里的 Mock 只会复述提示中的第一条资料，并带上它的 id。在当前阈值下，过线的常常只有第一条，所以输出看起来很稳。这是管道被固定住了，不是模型学会了挑选。换成真实模型后，它可能在几条资料之间选择，也可能写出 `[faq-pool]` 这种库里没有的 id。引用检查就是为了后面这种情况。

「延迟退房怎么收费」会命中退房规章。规章只说要问前台有没有空房，没有单价。检索路径必须复述这句，不能补出 30 元。单价在第 06 课的工具里。

入住问题的原因是 `ok`，回答末尾有 `[faq-checkin]`。游泳池的原因是 `low_score`。最后一段用一个故意写错引用的客户端，原因应当是 `unknown_citation`，回答里不能留下「全天开放」。

建议改一行：把练习里的 `build_lab_rag()` 改成 `build_lab_rag(min_score=0.0)` 再跑游泳池那一问。阈值没了，0 分也会进入生成。看完改回去。默认测试仍要求游泳池被拒绝。

## 常见坑

- 检索为空仍调用模型，模型就用对话里的常识补时间、价格。
- 引用检查失败后，仍把草稿和拒绝语拼在一起。半句假话已经出去了。
- 允许引用检索分很低、没过阈值的 id。那等于没有阈值。
- 用 Mock「总是复述第一条」来证明整条链路会推理。它只证明引用格式和拒绝分支。

## 口头自查

1. 最高分低于阈值时，为什么不再调用模型？
2. 草稿写了 `[faq-pool]`，最终回答里为什么连「全天开放」也没有？
3. 「延迟退房怎么收费」走检索时，为什么回答里不该出现 30 元？
