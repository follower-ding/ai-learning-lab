# 第 09 课：混合检索

第 03 课的字面向量对「我什么时候能进房间」大约是 0.227，对「今晚有乐队演出吗」是 0。人觉得前一句是在问入住。只拿第 05 课的 0.2 当门槛时，这句只高出 0.027。「下午可以住吗」反而在 0.197，该留却被拒绝；「时间」在 0.203，该拒却会留下。这几句挤在一起，一条向量分上放不下一道同时做对的缝。

这一课把关键词分和向量分都留下，规定怎么压到同一把尺子上、再按固定权重相加。第 03 课那三句收进固定查询集。无关句两路都是 0，融合分也是 0，不能因为多了一路就被抬过线。

下面的小数来自当前这份 `hotel_faq.json` 和 `TfidfEmbedder`。改了资料数字会变。要守住的是那条缝还在，不是背这三位小数。

## 学习目标

- 同一批文档上同时算出关键词分（BM25）和向量分（TF-IDF 余弦）。
- 说清楚两路原始分不能直接相加，压缩之后再按固定权重融合。
- 用固定查询集把三种结果分开：两路都支持、只有向量擦线、两路都没有足够依据。无关问法必须仍然拒绝。

## 概念笔记

两条路用的是同一套字符二元组，打分方式不同。向量仍然是第 03 课那个字面向量，不是神经网络嵌入。

余弦看方向。文档向量的长度里算进了这一条规章的全部二元组。「我什么时候能进房间」只对上「能进」和「房间」，点积来自这两个词，长度却来自整条入住规章，余弦掉到 0.227。问句里的「什么时候」在这份短问答里没有出现过，两条路都会丢掉这些二元组，不是它们把余弦拽下去的。

BM25 按词往上加。对上的词加一截，对不上的不加，也不减。文档长度只按 `b = 0.75` 做温和的归一，不会把整条向量的长度全部除掉。「能进」「房间」只出现在入住这一条里，idf 高，原始分是 3.161。`k1 = 1.2` 用的是常见默认值，不拿某一道题来调。

3.161 和 0.227 不是同一把尺子。直接相加，关键词路会把余弦淹没。按这一问的最高分去除，全库都很弱时第一名也会变成 1，一点点噪声就过线。这里用

```text
压缩后的关键词分 = 原始分 / (原始分 + 2.5)
融合分 = 0.5 × 向量分 + 0.5 × 压缩后的关键词分
```

3.161 压成 0.558，再和 0.227 各取一半，融合分是 0.393。0 还是 0。原始分再大也到不了 1。

混合比单路向量稳，是因为这两组问法在余弦上挨在一起，加权之后才分开。当前资料上：

| 问法 | 向量分 | 只用 0.2 | 融合分 | 只用 0.30 |
| --- | ---: | --- | ---: | --- |
| 下午可以住吗 | 0.197 | 拒绝 | 0.341 | 留下，入住 |
| 时间 | 0.203 | 留下，落到退房 | 0.259 | 拒绝 |
| 什么时候能入住 | 0.210 | 留下，落到宠物规章 | 0.266 | 拒绝 |
| 我什么时候能进房间 | 0.227 | 留下，只高出 0.027 | 0.393 | 留下，高出 0.093 |

「下午可以住吗」是入住问法，余弦却低于 0.2。「时间」更高一点，会落到某一条带「时间」的规章。「什么时候能入住」的第一名是宠物规章，因为正文里有「入住当天」，不是入住时间。这三句的余弦是 0.197、0.203、0.210。想留下下午那句，阈值就得低于 0.197，时间和错文档会一起进来；想挡住「时间」，阈值就得高于 0.203，下午那句进不来。

关键词路把「对上的字稀不稀有」算进来。「时间」在三篇规章里都有，idf 低，压缩后只有 0.315。下午那句对上了入住规章里的「下午」，压缩后是 0.486。各取一半以后，应当留下的问法里最低的是「下午可以住吗」，融合分 0.341；应当拒绝、又不是全 0 的问法里最高的是「早到怎么办」，融合分 0.274。0.30 放在这条缝里。换一种说法的那句，离拒绝线的距离从 0.027 变成大约 0.093，资料改一两个字不容易翻盘。

取两路的最大值，「时间」会变成 0.315，缝又没了。所以融合规定是加权，不是 max。

两路都是 0 的时候，融合是 0。「今晚有乐队演出吗」和「游泳池几点开放」不会因为多算了一路就出现依据。全 0 时打印出来的第一名是 id 的字母序，那不表示早餐更相关。

这一课仍然拒绝的边界：

- 「可以带狗吗」最高大约 0.189，第一名是取消规章，因为两边都有「可以」，不是宠物。两条都是字面分，调权重也变不出「导盲犬」。要同义词，得换嵌入模型，换完两条分和 0.30 都要重看。
- 「早到怎么办」的第一名是入住，正文里确实有「早到」，融合大约 0.274，不够。对上一个词，还不等于能回答。
- 「游泳池在停车场吗」会命中停车。问句里夹了库里真有的词，两路都会跟着走。融合分过线只说明词对上了，正文里有没有游泳池，交给第 05 课去读。过线不等于把文档直接当成答案。

固定查询集在 `src/ailab/data/hybrid_queries.json`。练习报告的每一行都有 `vector`、`sparse`、`raw` 和 `id`。`sparse` 是压缩后的分，`raw` 才是 BM25 原始分。向量低、关键词高，是问法换了字；两路都低，是库里没有这件事；融合过线但 id 不对，才去看权重和阈值。不要一失败就改期望。

资料只有 7 条，两路都给每一条打分，再排序。不先各取一个 top-k 然后只融合那几条。候选变多以后先宽后窄，是第 10 课的事，这一课不混进去。

`accepted` 为空就不要调用模型。练习在乐队那一问上直接印出第 05 课的拒绝句。融合分不能拿去和第 05 课的 `DEFAULT_MIN_SCORE` 比，两把尺子刻度不同。

## 常见坑

- 把 BM25 原始分和余弦加在一起。一个是 3，一个是 0.23，加总被关键词路主导。
- 除以这一问的最高分。弱查询的第一名也会变成 1。
- 取两路的最大值。「时间」的向量分已经超过 0.2，最大值会把它重新放进来。
- 把混合理解成突然听得懂「狗」和「宠物」。字面证据对不上，就应当拒绝。
- 融合过线就把正文交给客人，不再做第 05 课的引用检查。分数只决定进不进生成。
- 为了压住某一个字去改 `k1` 或 `b`。这两个数保持默认。缝不对，回到查询集上看是哪一路的分变了，再重定 `DEFAULT_HYBRID_MIN_SCORE`。

## 口头自查

1. 「我什么时候能进房间」的余弦为什么会到 0.227？同一句的 BM25 原始分为什么还能到 3 附近？
2. 只看向量分，为什么没有一条阈值能同时留下「下午可以住吗」、拒绝「时间」？取两路最大值时，「时间」会怎样？
3. 「可以带狗吗」两路都不高。把权重从 0.5 改到 0.9，它会命中宠物规章吗？缺的是哪一种证据？

口头回答即可。说不顺的那一题，回到概念笔记里的对照表，对照练习输出再讲一遍。
