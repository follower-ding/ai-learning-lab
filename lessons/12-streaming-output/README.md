# 第 12 课：流式输出

真实接口可以逐段返回。第 05 课的引用检查要看到完整的 `[faq-...]` 才能决定留还是扔。半句假话往往比这个方括号先到。

这一课把两种办法并排跑一次。最终回答都不保留被作废的半句。差别只在中途：客人看不看得到那半句。

## 学习目标

- 用「先收齐再检查」和「边打印边检查」送同一段草稿。
- 分清两件事：中途屏幕上有没有那半句，最终回答里留不留下。
- 最终回答仍是第 05 课的结果。该扔的整段换成拒绝语，不把半句和拒绝语拼在一起。

## 概念笔记

离线不打开流式接口，也不需要 API 密钥。`complete` 仍一次返回整段。`split_draft` 再把它切开，当作逐段到达：

- 句号（。）结束一段。
- `[...]` 单独成一段。没有右方括号时，从 `[` 起剩下的字单独成段，不算一条已经写完的引用。

所以「游泳池全天开放。」会先于 `[faq-pool]` 到达。这是逐段返回的替身，不是第二条网络连接。

第 05 课的 `RagPipeline.answer` 不改。它仍然先收齐，再 `apply_citation_policy`。引用缺失或引用了这次没检索到的 id，整段换成「知识库里没有足够依据，不能回答。」草稿不留。这一课另开 `answer_streaming`，最终回答直接用同一次检查的结果。

两种办法：

| 办法 | 中途屏幕 | 最终回答 |
| --- | --- | --- |
| 先收齐再检查 | 没有字。作废的半句不会出现 | 检查留下的草稿，或那句拒绝。半句不留 |
| 边打印边检查 | 每一段先推上屏幕。作废的半句会先出现 | 和上一行相同。半句不留 |

合约就这两列。测试按 `streamed` 和 `final_answer` 检查，不靠读说明。

边打印不是「先把整段印完再看一眼」。未知引用的方括号一闭合，后面的段就不再推。草稿若是「游泳池全天开放。来源：[faq-pool] 而且免费。」，中途有「游泳池全天开放。」，没有「而且免费」。最终回答里两句都没有。

还没看到完整引用时，不能拿前缀去做「缺少引用」的拒绝。第一段往往只有「……14:00。」，方括号还在后面。提前拒绝会把本来能留下的回答扔掉。缺引用要等流结束，再对整段做第 05 课的检查。方括号没闭合也一样，它还不是 `[faq-...]`。

一条未知引用会让整段作废，包括前面写对的那半句。边打印可以在中途看见「14:00」和「全天开放」，最终回答里两句都不留。先收齐则两句都不会出现。

分数低于 `DEFAULT_MIN_SCORE` 时，两种办法都不调用模型。中途没有草稿，原因是 `low_score`。这和第 05 课相同。

第 06 课到第 08 课的工具协议不动。允许列表仍然只有 `lookup_policy` 和 `quote_late_checkout`。

## 跑起来

```bash
python lessons/12-streaming-output/exercise.py
```

应当先看到入住问题：两种办法的原因都是 `ok`，最终回答里有 `14:00` 和 `[faq-checkin]`。先收齐的中途是「（无）」。边打印的第一段里还没有 `[faq-`。

然后是引用了 `[faq-pool]` 的草稿。先收齐的中途仍是「（无）」，最终回答是那句拒绝。边打印的中途有「游泳池全天开放。」，没有「而且免费」。最终回答和先收齐的相同，里面没有这半句。

接着是没写引用的草稿。边打印的中途有「14:00」和「不用看来源」，最终回答里没有。原因是 `missing_citation`。

最后是「游泳池几点开放？」。两种办法的原因都是 `low_score`，模型不被调用，中途没有字。退出码为 0。没有 API 密钥也能跑。

建议改一处：在 `src/ailab/streaming.py` 里，让边打印的 `final_answer` 改成中途各段拼起来的字符串，再跑练习。最终回答会留下「游泳池全天开放」，练习以退出码 1 结束。看完改回去。不要为了变绿去改 `tests/test_streaming.py` 里的期望。

再改一处也可以：先收齐时把 `split_draft` 的每一段放进 `streamed`。中途会出现作废的半句，练习同样以退出码 1 结束。看完改回去。

## 常见坑

- 把中途各段拼起来当作最终回答。客人已经看见的半句假话就留下了。
- 半句一到就做完整的引用检查。这时还没有 `[faq-...]`，会被当成 `missing_citation`，把后来写对的回答提前扔掉。
- 方括号还没闭合就当成未知引用。`[faq-pool` 还不是一条 id。
- 名字叫先收齐，却把每一段先 `print` 出去。检查还没做，半句已经在屏幕上。
- 未知引用闭合之后仍把后面的段推完。检查并没有在边上看。
- 为了流式去改 `RagPipeline.answer`，让第 05 课不流式的那次也漏出半句。
- 为了这一课去改第 06 课到第 08 课的工具协议。

## 口头自查

1. 「游泳池全天开放。」已经到了，`[faq-pool]` 还没有到。这时为什么还不能决定留还是扔？
2. 边打印时客人已经看见这半句。最终回答为什么仍是那句拒绝，而不是半句后面再接一句拒绝？
3. 同一段草稿，先收齐再检查为什么连这半句都不让客人看见？中途的「（无）」和最终回答各算哪一次输出？

口头回答即可。说不顺的那一题，把练习里两种办法的「中途」和「最终回答」并排再讲一遍。
